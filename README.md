# Проект: Классификация токсичных комментариев

## Кратко

Модель машинного обучения для определения токсичности комментариев на русском языке. Логистическая регрессия с TF-IDF векторизацией.

## Метрики

| Показатель | Значение |
|------------|----------|
| Accuracy   | 0.86     |
| F1-score   | 0.86     |
| AUC-ROC    | 0.92     |

## Технологии

- Pandas, NumPy
- Scikit-learn (TF-IDF, LogisticRegression)
- razdel (токенизация)
- pymorphy2 (лемматизация)

## Процесс

Очистка - Токенизация - Лемматизация - TF-IDF - Обучение

## Пример

```
"Ты вообще идиот" → Токсичный (уверенность 94%)
"Спасибо за помощь" → Не токсичный (уверенность 92%)
```
