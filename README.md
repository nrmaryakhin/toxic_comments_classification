# toxic_comments_classification

- Классификация токсичных (метка - 1) и вежливых (метка - 0) комментариев
- Производится предобработка текста с применением токенизации, лематизации
- Вычисляется TF-IDF мера для оценки важности слова
- Сравниваются 3 модели LogisticRegression, LinearSVC, MultinomialNB по метрике f1_score (в зависимости от задачи метрику можно изменить)
